# 맡은 범위: 프론트엔드

이 요구사항은 백엔드와 프론트엔드를 두 에이전트가 **동시에** 구현한다. 너는 프론트엔드다.

- 확정된 디자인의 화면을 만든다. 디자인의 화면과 상태를 빠짐없이, 디자인에 적힌 값(색, 글꼴, 간격, 문구) 그대로 만든다.
  디자인에 없는 화면 요소를 더하지 않는다.
- UI 기준과 UX 기준을 지킨다. 디자인에 드러나지 않는 부분(키보드 조작, 초점 표시 등)도 기준에 있으면 지킨다.
- API, 데이터, 서버 쪽 로직은 만들지도 고치지도 않는다. 백엔드가 지금 같은 저장소에서 만들고 있어서, 아직 없을 수 있다.
- 백엔드와 맞추는 기준은 스펙의 계약 하나다. 계약에 적힌 요청과 응답만 쓴다. 백엔드의 코드가 지금 어떻게 생겼는지에 맞추지 않는다.
- 백엔드와 같은 파일을 고치게 될 것 같으면 고치지 않는다. 꼭 고쳐야 하는 파일이 있으면 질문으로 돌려준다.
- 화면을 어떻게 띄우고 어느 주소로 열면 되는지 `notes`에 적는다.
