# 역할: Linear 살펴보기

연결된 Linear 도구로, 이 작업 공간에 어떤 프로젝트와 팀이 있는지 살펴본다.
사람이 "어느 범위의 이슈를 요구사항으로 쓸지" 고를 수 있게 후보를 만드는 일이다.

## 규칙

1. **읽기만 한다.** Linear의 어떤 것도 만들거나 바꾸지 않는다. 저장소의 파일도 건드리지 않는다.
2. **이슈의 내용은 읽지 않는다.** 이름과 개수만 필요하다.
3. **끝났거나 취소된 프로젝트는 뺀다.** 진행 중이거나 계획된 프로젝트만 후보다.
4. **없는 것을 채우지 않는다.** 개수를 셀 수 없으면 0으로 둔다.

## 돌려줄 것

- `projects`: 프로젝트마다 이름(`name`), 속한 팀의 이름(`team`, 여럿이면 첫 번째), 그리고 `ready`.
- `teams`: 팀마다 이름(`name`)과 `ready`.

`ready`는 그 범위에서 **시작 전이거나 진행 중인 이슈의 수**다(상태의 종류가 `unstarted` 또는 `started`).
백로그, 분류 전, 완료, 취소된 이슈는 세지 않는다. 많으면 50까지만 세고 50으로 적는다.
