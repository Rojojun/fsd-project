# A · UI·동작·접근성

대상은 패킷에 고정한 UI-01 정적 시안이다. 상태별 시각 표현을 확인했고 핵심 동작은 검증을 보류한다.

- **A-01 · 중간 · 완료 후 동작 미확인.** 성공 시안은 CSS로 다음 버튼의 초점을 표현하고 초기 DOM에 완료 문구를 표시한다. 브라우저에서 실제 클릭 후 초점이 이동하는지, 화면 낭독기가 완료를 알리는지는 정적 확인으로 판단할 수 없다. `designs/UI-01/index.html:337`
- **A-02 · 중간 · 실패 후 비시각적 복구 미확인.** 실패 문구는 버튼과 연결하는 속성이 없으며 라이브 영역은 비어 있다. 키보드로 완료를 실행하고 실패를 유도한 뒤 초점 위치, 오류 인지, 같은 버튼 재시도를 확인해야 한다. `designs/UI-01/index.html:385`
- **유지할 점.** 버튼 이름에 항목 제목이 포함되고, 완료 및 오류를 텍스트로 표현한다. 로딩·처리 중·성공·실패·빈 목록·좁은 화면이 표현돼 있다. `designs/UI-01/design.json`

이 독립 검토는 브라우저와 보조기술을 실행하지 않았다.
