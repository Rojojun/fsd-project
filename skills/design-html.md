# 그리는 도구: 단일 HTML 파일

디자인 도구가 연결되어 있지 않다. 화면을 HTML 파일 하나로 그린다.
이 파일은 브라우저로 바로 열 수 있고, Claude 아티팩트로 그대로 올릴 수 있어야 한다.

- 파일 하나에 모두 담는다. 스타일과 스크립트는 파일 안에 쓴다. 바깥 파일, 글꼴, 이미지, 라이브러리를 불러오지 않는다.
- `<!doctype html>`로 시작하고, `<title>`은 두세 낱말의 이름으로 쓴다.
- 화면의 상태마다 구역을 따로 두고, 구역 제목은 `screens`의 이름과 같게 한다. 한 파일을 위에서 아래로 읽으면 모든 상태가 보여야 한다.
- 실제 화면처럼 보이게 그린다. 회색 상자만 늘어놓지 않는다. 내용은 스펙에 나온 예시 값을 쓴다.
- 색은 `:root`의 변수로 정하고, 밝은 화면과 어두운 화면 모두에서 읽히게 한다
  (`@media (prefers-color-scheme: dark)`). `body`에 배경색을 준다.
- 휴대폰 너비에서도 가로로 밀리지 않게 한다.
- 디자인 설명이나 주석 문단을 화면 안에 넣지 않는다. 설명은 돌려주는 `screens`에 적는다.
- 색, 글꼴, 간격의 값은 UI 기준에 적힌 것을 그대로 쓴다.
