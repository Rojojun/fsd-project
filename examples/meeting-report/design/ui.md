# UI 기준

회의 보고 시스템의 화면이 어떻게 보이는지 정한다. 디자인과 프론트엔드 구현, 그리고 UI 관점의 검토가 이 문서를 기준으로 삼는다.

## 글꼴

- 시스템 글꼴을 쓴다: `system-ui, -apple-system, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`.
- 크기는 셋만 쓴다.

| 쓰임 | 크기 | 굵기 | 줄 높이 |
|---|---|---|---|
| 화면 제목 | 24px | 700 | 1.3 |
| 본문 (항목 제목, 버튼, 안내) | 16px | 400 (버튼은 600) | 1.5 |
| 보조 글 (날짜, 개수, 상태 표시) | 14px | 400 | 1.5 |

## 색

색은 `:root`의 변수로만 쓴다. 밝은 화면과 어두운 화면의 값을 함께 정한다. 어두운 화면은 운영체제 설정(`prefers-color-scheme: dark`)을 따른다.

| 변수 | 쓰임 | 밝은 화면 | 어두운 화면 |
|---|---|---|---|
| `--bg` | 화면 배경 | `#ffffff` | `#14181f` |
| `--surface` | 목록, 카드의 바탕 | `#f7f8fa` | `#1b212a` |
| `--text` | 본문 | `#182333` | `#e8ecf1` |
| `--text-muted` | 보조 글 | `#5b6b7c` | `#9aa8b6` |
| `--border` | 구분선, 테두리 | `#dbe1e6` | `#2a323d` |
| `--accent` | 주 버튼 배경, 초점 테두리, 링크 | `#205477` | `#6fb1d9` |
| `--on-accent` | 주 버튼의 글자 | `#ffffff` | `#0d1117` |
| `--success` | 완료 표시 | `#1f7a4d` | `#5cc28f` |
| `--danger` | 오류 안내 | `#b42318` | `#f27a6f` |

- 글자와 바탕의 대비는 4.5:1 이상이어야 한다. 위 값의 조합은 이것을 만족한다. 새 조합을 만들지 않는다.

## 간격과 배치

- 간격은 4px의 배수만 쓴다. 주로 쓰는 값: 4, 8, 12, 16, 24, 32.
- 내용의 최대 너비는 720px이고 가운데에 둔다. 좌우 여백은 화면이 좁을 때 16px, 넓을 때 24px.
- 목록의 한 줄: 위아래 안쪽 여백 16px, 좌우 16px. 줄과 줄 사이는 `--border` 1px 선으로 나눈다.
- 한 줄 안에서 글 영역과 오른쪽의 버튼(또는 상태 표시) 사이는 16px 이상 띄운다.
- 화면 제목과 그 아래 내용 사이는 24px.

## 컴포넌트

**버튼**
- 높이 36px, 좌우 안쪽 여백 16px, 모서리 6px, 글자 16px 600.
- 주 버튼: `--accent` 바탕, `--on-accent` 글자. 한 줄(또는 한 영역)에 주 버튼은 하나만 둔다.
- 보조 버튼: 투명 바탕, `--border` 1px 테두리, `--text` 글자.
- 누를 수 없는 상태: 불투명도 50%, 마우스 모양은 기본.
- 처리 중: 누를 수 없는 상태로 바꾸고, 글자를 "처리 중"으로 바꾼다.

**상태 표시** (예: 완료)
- 아이콘 16px와 글자를 함께 쓴다. 아이콘만 쓰지 않는다.
- 완료는 `--success` 색의 체크 아이콘과 "완료" 글자.

**목록**
- `--surface` 바탕, 모서리 8px, `--border` 1px 테두리.
- 항목 제목은 한 줄이 넘으면 줄을 바꾼다. 말줄임으로 자르지 않는다.

**안내 문구** (빈 목록, 오류)
- 목록 자리의 가운데에, 위아래 32px 여백을 두고 보조 글 크기로 쓴다. 오류 안내는 `--danger` 색.

**초점 표시**
- 키보드로 초점이 온 요소에는 `--accent` 색 2px 테두리를 요소 바깥 2px 띄워서 그린다(`outline-offset: 2px`). 없애지 않는다.

## 날짜와 숫자

- 날짜는 `2026-11-17` 형식으로 쓴다. 날짜 앞에 "생성일" 같은 이름표를 붙이지 않는다.
- 시각은 화면에 보이지 않는다(요구사항이 따로 정하면 따른다).
- 날짜는 이용자 컴퓨터의 시간대 기준으로 바꿔 보여 준다.

## 문구

- "~합니다"체로 짧게 쓴다. 느낌표를 쓰지 않는다.
- 버튼은 동사 하나로 쓴다: "완료", "삭제", "다시 시도".
- 같은 것은 화면 어디에서나 같은 낱말로 부른다. 이 시스템에서는 "액션 아이템"이라고 쓴다("할 일", "태스크"라고 쓰지 않는다).
