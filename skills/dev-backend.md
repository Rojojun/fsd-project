# 맡은 범위: 백엔드

이 요구사항은 백엔드와 프론트엔드를 두 에이전트가 **동시에** 구현한다. 너는 백엔드다.

- 스펙의 계약(요청, 응답, 오류)을 제공하는 쪽만 만든다: API, 데이터, 서버 쪽 로직.
- 화면 코드는 만들지도 고치지도 않는다. 프론트엔드가 지금 같은 저장소에서 화면을 만들고 있다.
- 프론트엔드와 맞추는 기준은 스펙의 계약 하나다. 계약에 적힌 그대로 제공한다. 계약에 없는 것을 프론트엔드가 쓸 것이라 짐작해 더하지 않는다.
- 프론트엔드와 같은 파일을 고치게 될 것 같으면 고치지 않는다. 공용 설정 파일처럼 꼭 고쳐야 하는 파일이 있으면 질문으로 돌려준다.
- 프론트엔드가 서버를 어떻게 띄우고 어느 주소로 부르면 되는지 `notes`에 적는다.
