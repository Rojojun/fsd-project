- 대상: REVIEW_PACKET에 고정한 UI-01, `28a1d0f`
- 수신: A·B 독립 검토 수신 완료.
- 검토 상태: 보류 — 키보드 실패 복구의 연속 시나리오와 보조기술 증거 미확인.
- 대상 판정: 개선 필요. B-01의 문구 개선과 B-02의 승인 연결은 이번 라운드의 후속 항목이다.
- 사용자 결정: UI-01에 하네스를 시범 적용하기로 했다. 이 기록은 기존 FSD 승인 이력과 별개다.

| 지적 | 현재 증거 | 조치와 재개 조건 |
| --- | --- | --- |
| A-01 성공 후 초점·안내 | Chrome S-28·S-29에서 키보드 완료 후 초점 이동 확인. S-23에서 성공 메시지가 `aria-live` 영역에 들어감 확인. | 실제 낭독 확인은 보류. 다음 QA에서 보조기술과 브라우저 조합 및 들은 메시지를 기록한다. |

## 다음 verify에 넘길 필수 시나리오

1. Chrome에서 Tab으로 대상 행의 완료 버튼에 초점을 두고 Enter로 실행한다. 첫 POST는 HTTP 500으로 응답시킨다.
2. 동일 행에 오류가 표시되고 같은 완료 버튼이 활성화되며, 초점이 그 버튼으로 돌아오는지 확인한다. 화면 낭독기를 켠 별도 실행에서 오류·재시도 방법을 인지할 수 있는지 기록한다.
3. 키보드로 같은 버튼을 다시 활성화한다. 동일 항목에 POST가 한 번 더 가고 오류가 사라지며 완료 표시로 전환되는지 확인한다.
4. 필수 실행이 스킵되거나 환경 제약으로 실행되지 않으면 이 라운드의 검토 완료를 보류한다.

실행 근거: 예제 루트에서 `node node_modules/@playwright/test/cli.js test e2e/UI-01/ --workers=2 --output=/private/tmp/fsd-ui01-design-pilot` 실행. Chrome **38개 통과**. 이 실행은 기존 테스트 모음이며, 위 연속 시나리오와 실제 화면 낭독 검사는 포함하지 않았다.
